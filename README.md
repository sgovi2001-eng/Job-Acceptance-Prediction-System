# Job-Acceptance-Prediction-System
 ****Project Overview****
The Job Acceptance Prediction System is a Machine Learning-based application that predicts whether a candidate is likely to accept a job offer based on various factors such as salary, experience, education, location, and job-related attributes.

 ****Objectives****
 
   1. Predict job offer acceptance.
   2. Assist recruiters in making data-driven hiring decisions.
   3. Reduce hiring time and recruitment costs.

****Technologies Used********

   1. Python
   2. Pandas
   3. NumPy
   4. Scikit-learn
   5. Streamlit / Flask
   6. Matplotlib
   7. Jupyter Notebook
